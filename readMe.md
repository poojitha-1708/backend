# Online Courses API

A RESTful API built using Node.js, Express.js, MongoDB, and Mongoose to manage online courses. It supports CRUD operations, filtering, sorting, and retrieving completed courses.

## Features

- Create a new course
- Retrieve all courses
- Retrieve a single course by ID
- Update course details
- Delete a course
- Filter courses by platform
- Sort courses by learning hours
- Filter courses by completion status
- Retrieve completed courses
- Validate course data
- Connect to MongoDB Atlas
- Handle errors with appropriate HTTP status codes

## Technologies Used

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- Postman
- dotenv
- Nodemon

## Installation and Setup

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Navigate to the project folder

```bash
cd online-courses-api
```

### 3. Install dependencies

```bash
npm install
```

If the dependencies are not listed in `package.json`, install them using:

```bash
npm install express mongoose dotenv
npm install --save-dev nodemon
```

### 4. Configure environment variables

Create a `.env` file in the root directory.

```env
MONGO_URI=your_mongodb_atlas_connection_string
PORT=3000
```

Replace the placeholder with your MongoDB Atlas connection string.

### 5. Start the server

```bash
npm run dev
```

The server will run at:

`http://localhost:3000`

## Course Data Model

| Field | Type | Description |
|---|---|---|
| `course` | String | Name of the course; required |
| `hours` | Number | Learning hours; between 1 and 500 |
| `platform` | String | `youtube`, `udemy`, `coursera`, or `other` |
| `completed` | Boolean | Course completion status; defaults to `false` |
| `startedOn` | Date | Course start date; defaults to the current date |

## API Endpoints

Base URL: `http://localhost:3000/courses`

| Method | Endpoint | Description |
|---|---|---|
| GET | `/courses` | Retrieve all courses |
| GET | `/courses/:id` | Retrieve a course by ID |
| POST | `/courses` | Create a new course |
| PUT | `/courses/:id` | Update an existing course |
| DELETE | `/courses/:id` | Delete a course |
| GET | `/courses/completed` | Retrieve completed courses |

## Filtering and Sorting

### Filter by platform

```http
GET /courses?platform=youtube
```

Retrieves courses available on YouTube.

Supported platforms: `youtube`, `udemy`, `coursera`, and `other`.

### Sort by learning hours

```http
GET /courses?sort=hours
```

Sorts courses in ascending order, from the lowest to the highest number of hours.

```http
GET /courses?sort=-hours
```

Sorts courses in descending order, from the highest to the lowest number of hours.

### Filter by completion status

```http
GET /courses?completed=true
```

Retrieves only completed courses.

```http
GET /courses?completed=false
```

Retrieves courses that have not been completed.

### Combine filtering and sorting

```http
GET /courses?platform=youtube&sort=hours
```

Retrieves YouTube courses sorted by learning hours in ascending order.

## Example Requests

### Create a course

**Method:** POST

**URL:** `http://localhost:3000/courses`

**Body:** Select Body → raw → JSON in Postman.

```json
{
  "course": "Node.js for beginners",
  "hours": 12,
  "platform": "youtube"
}
```

Example response:

```json
{
  "_id": "YOUR_COURSE_ID",
  "course": "Node.js for beginners",
  "hours": 12,
  "platform": "youtube",
  "completed": false,
  "startedOn": "2026-10-09T00:00:00.000Z"
}
```

The actual ID and date will be generated by MongoDB and Mongoose.

### Update a course

**Method:** PUT

**URL:** `http://localhost:3000/courses/YOUR_COURSE_ID`

**Body:**

```json
{
  "hours": 20,
  "completed": true
}
```

### Delete a course

**Method:** DELETE

**URL:** `http://localhost:3000/courses/YOUR_COURSE_ID`

Replace `YOUR_COURSE_ID` with the actual course ID.

## Error Handling and Validation

The API handles invalid requests and returns appropriate HTTP status codes.

| Status Code | Description |
|---|---|
| `200 OK` | Request completed successfully |
| `201 Created` | Course created successfully |
| `400 Bad Request` | Invalid ID or course data |
| `404 Not Found` | Course or route not found |
| `500 Internal Server Error` | Unexpected server error |

Validation rules include:

- Course name is required.
- Learning hours must be between 1 and 500.
- Platform must be one of the supported values.
- Course IDs must be valid MongoDB ObjectIds.

## Testing with Postman

1. Start the server using `npm run dev`.
2. Open Postman.
3. Select the required HTTP method.
4. Enter the API endpoint.
5. For POST and PUT requests, select Body → raw → JSON.
6. Enter the request data and click Send.
7. Verify the response status and returned data.
